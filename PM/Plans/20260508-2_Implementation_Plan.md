# 아이디/비밀번호 찾기 (Level 2) 구현 계획서

사용자님의 선택에 따라, **외부 본인인증(문자 인증 등) 없이 내부 DB 정보를 활용하여 즉시 임시 비밀번호를 발급해 주는 'Level 2' 방식**으로 아이디 및 비밀번호 찾기 기능을 구현합니다.

## 🚨 User Review Required (사용자 피드백 필요)

> [!IMPORTANT]
> 본 기획의 특성 상 사용자가 이름과 전화번호만 알면 이메일의 일부를 알아낼 수 있고, 이메일/이름/전화번호 3가지를 모두 알면 비밀번호를 초기화할 수 있습니다.
> 임시 비밀번호는 발급 즉시 화면에 노출되며, 사용자가 직접 복사해서 로그인해야 합니다. B2B 파트너센터의 초기 MVP 버전으로 적합한 스펙입니다. 진행해도 좋을지 확인 부탁드립니다.

## 🛠 Proposed Changes (수정/추가될 파일 내역)

### 1. Backend (FastAPI)

#### [MODIFY] `schemas/user.py`
- 아이디 찾기 요청/응답 스키마 (`FindIdRequest`, `FindIdResponse`) 추가
- 비밀번호 찾기 요청/응답 스키마 (`ResetPasswordRequest`, `ResetPasswordResponse`) 추가

#### [MODIFY] `routers/user.py`
- `POST /users/find-id` API 추가: 이름과 전화번호가 DB와 일치하면, 이메일 앞자리 2글자만 남기고 마스킹하여 반환 (예: `pm*******@naver.com`).
- `POST /users/reset-password` API 추가: 이메일, 이름, 전화번호가 DB와 일치하면, 보안 규정(영문, 숫자, 특수문자 포함 8자리)을 만족하는 랜덤 임시 비밀번호를 생성하여 화면에 반환하고 DB 비밀번호를 변경.

### 2. Frontend (React)

#### [MODIFY] `LoginPage.tsx`
- 로그인 폼 하단(또는 비밀번호 입력칸 근처)에 `아이디 찾기 | 비밀번호 찾기` 링크 추가.

#### [NEW] `FindIdPage.tsx`
- 이름과 전화번호를 입력받아 아이디(마스킹된 이메일)를 찾아주는 화면 제작.
- 결과 팝업/화면 후 로그인 페이지로 돌아가기 버튼 제공.

#### [NEW] `FindPasswordPage.tsx`
- 이메일, 이름, 전화번호를 입력받아 정보가 일치하면 **화면에 임시 비밀번호를 크게 띄워주는** 화면 제작.
- 보안을 위해 "발급된 임시 비밀번호로 로그인 후 반드시 비밀번호를 변경해주세요." 안내 문구 포함.

#### [MODIFY] `App.tsx`
- 새로 만든 두 페이지에 대한 React Router 경로(`/find-id`, `/find-password`) 추가.

## ✅ Verification Plan (검증 계획)

1. **아이디 찾기 테스트**:
   - 기존 생성된 더미 계정(`dummy1@moki.com`, `테스트점주_1`, `010-8888-0001`) 정보를 입력하여 `du***@moki.com` 형태로 마스킹되어 잘 나타나는지 확인.
2. **비밀번호 초기화 테스트**:
   - 올바른 정보 입력 시 무작위 8자리 임시 비밀번호가 생성되는지 브라우저에서 확인.
   - 틀린 정보 입력 시 "입력하신 정보와 일치하는 계정이 없습니다." 경고가 잘 뜨는지 확인.
3. **임시 비밀번호 로그인 테스트**:
   - 발급된 임시 비밀번호를 복사하여 정상적으로 로그인에 성공하는지 검증.
