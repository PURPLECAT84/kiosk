# MOKI (모두의 키오스크) 프로젝트 통합 상태 보드

이 문서는 집과 회사에서 Antigravity와의 대화 맥락을 끊김 없이 이어가기 위한 **프로젝트 상태, 기획안, 대화 기록 통합 문서**입니다. 새로운 기기에서 대화를 시작할 때 이 문서 하나만 읽히면 모든 컨텍스트가 복구됩니다.

---

## 📌 1. [우리의 개발 원칙]

1. **연속성 유지:** 이 통합 문서 기반으로 집과 회사의 개발 맥락을 완벽히 동기화합니다.
2. **유연한 기획 대응:** 기획안이나 목표가 변경되면 이 문서에 반영하여 방향을 조정합니다.
3. **🔥 초보자용 FastAPI 교보재 주석 지침 (필수):** 백엔드 코드는 향후 FastAPI 학습용 교보재로 활용될 예정입니다. 따라서 아무리 사소하고 기본적인 문법/흐름이라도 **완전 초보자가 쉽게 이해하고 학습할 수 있도록 코드 전체에 매우 꼼꼼하고 상세한 멘토링 주석과 아키텍처 설명을 작성**해야 합니다. 이는 앞으로 작성할 모든 백엔드 기능에 상시 적용되는 원칙입니다.

## 🚀 4. 상세 기획안 원문 (V2.1)
*   **Version:** 2.1 (2026.05.04)
*   **Status:** 외식형 주문 출력 로직 최적화 버전

### 4.1 사업 개요 (Business Strategy)
*   **사업명:** 범용 중고 키오스크 솔루션 (모두의 키오스크)
*   **비즈니스 모델:** 사용 기간만큼 지불하는 SaaS 구독 모델 및 중고 기기 리퍼비시 렌탈 사업.

### 4.2 기술 스택 (Technical Stack)
*   **Backend:** Python (FastAPI), uv (환경 관리)
*   **Database/Auth:** Supabase (PostgreSQL, Real-time)
*   **Partner Web:** React (Vite) - 점주용 반응형 관리 페이지
*   **Kiosk Client:** Flutter (Windows/Android) - 크로스 플랫폼 앱

## 📚 5. 이전 대화 기록 보관소

### 📅 2026-06-09 (외부 네트워크 테스트 지원 및 키오스크 대문화면 탑재)

- **[요청 사항]** 외부 기기(회사 컴퓨터 등)에서 파트너센터와 키오스크 화면에 접속할 수 있도록 세팅을 변경하고, 키오스크 최초 진입 시 터치해서 진입할 수 있는 "대문화면(시작화면)" 추가 요청.
- **[진행 내용]**
  1. **외부 접속 세팅 고도화:**
     - **프론트엔드 (React):** `package.json` 내 dev 스크립트를 `"vite --host 0.0.0.0"`으로 변경하여 로컬 공유망 내 모든 IP에서의 접속을 수신 대기시켰습니다.
     - **키오스크 (Flutter):** `main.dart`의 `backendUrl`을 웹 기동 시(`kIsWeb`) 현재 브라우저의 접속 URL(`Uri.base.host`)을 참조하여 `http://[서버IP]:8000`으로 동적 포워딩하도록 리팩토링했습니다. 외부 기기에서 브라우저를 통해 접속해도 정상 통신됩니다.
  2. **키오스크 대문화면 및 자동 복귀 타이머 구현:**
     - `_isStarted` 상태를 신설하여 앱 최초 기동 시 매장명과 터치 안내가 반짝이는 **대문화면 UI**를 렌더링하고, 클릭 시 메인 상품 화면으로 진입시켰습니다.
     - 메인 화면 전체를 `GestureDetector`로 묶어, 사용자가 기기 조작을 멈추고 **2분이 경과하면 자동으로 장바구니를 비우고 최초 대문화면으로 돌아가도록** 하는 `Inactivity Reset Timer`를 구현해 상용 제품급 완성도를 확보했습니다.
- **[주의 및 테스트 가이드]**
  - **백엔드 (FastAPI) 외부 개방:** 외부 컴퓨터에서 접속하려면 백엔드 기동 시 반드시 포트와 호스트를 바인딩하여 띄워야 합니다.
    *   명령어: `uvicorn main:app --host 0.0.0.0 --port 8000 --reload`
  - **Flutter Web 외부 개방:** Flutter Web 구동 시 호스트와 포트를 외부로 열어 띄워야 합니다.
    *   명령어: `flutter run -d chrome --web-hostname 0.0.0.0 --web-port 8080`
  - **교보재 주석 지침:** 백엔드 FastAPI 코드 작업 시, 사소하고 쉬운 기능이라도 완전 초보자가 따라 배울 수 있도록 **가장 꼼꼼하고 상세하게 멘토링용 주석을 작성**해야 합니다.
