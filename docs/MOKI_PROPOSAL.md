# [기획안] 범용 중고 키오스크 솔루션: 모두의 키오스크 (MOKI)

## 1. 사업 개요 (Business Overview)
### 1.1 배경 및 목적
*   **시장 문제:** 무인 매장의 급증과 높은 폐업률로 인해 중고 키오스크 매물은 쏟아지나, 제조사별 폐쇄적인 소프트웨어 구조와 VAN사 종속성으로 인해 재활용률이 매우 낮음.
*   **해결 방안:** 하드웨어 제조사와 VAN사에 상관없이 설치 가능한 범용 키오스크 OS/앱을 보급하여 중고 기기의 자산 가치를 회복시키고 점주의 초기 진입 비용을 혁신적으로 절감.

### 1.2 비즈니스 모델 (Revenue Model)
*   **구독형 모델(SaaS):** 하드웨어를 보유한 점주에게 소프트웨어 이용 권한 부여 (월 구독료 발생).
*   **렌탈 연계 모델:** 중고 하드웨어 매입 후 솔루션을 탑재하여 저렴한 가격에 단기/장기 렌탈 서비스 제공.

## 2. 기술 스택 및 개발 환경 (Technical Stack)
| 구분 | 기술 사양 | 비고 |
| :--- | :--- | :--- |
| **Backend** | Python 3.12+, FastAPI, uv (패키지 관리) | 비동기 처리 및 빠른 API 성능 |
| **Database/Auth** | Supabase (PostgreSQL) | 실시간 데이터 동기화 및 간편 인증 |
| **Admin Web** | React (Vite) | 파트너센터 (반응형 웹) |
| **Kiosk Client** | Flutter (Windows/Android 공용) | 멀티 플랫폼 대응 및 UI 일관성 |
| **PG Middleware** | PortOne V2 (Offline Bridge) | 중고 단말기(NICE, KCP 등) 통합 제어 |
| **Infrastructure** | Render (초기) $\rightarrow$ AWS (확장 시) | 인프라 관리 최소화 |

## 3. 시스템 아키텍처 (System Architecture)
*   **사용자(점주):** 파트너센터(Web)에서 상품 및 매장 정보 설정.
*   **키오스크(Client):** 설치된 기기에서 API를 통해 상품 정보를 호출하고, 결제 시 PortOne Bridge와 통신.
*   **중앙 서버(FastAPI):** 모든 결제 검증, 이용권 관리, 통계 데이터 처리.
*   **DB(Supabase):** 회원 정보 및 상품 이미지(Storage), 실시간 주문 내역 저장.

## 4. 상세 기능 명세 (Functional Specifications)
### 4.1 파트너센터 (Partner Center - Web)
*   **계정 관리:** 소셜 로그인(구글/카카오/네이버) 연동 및 사업자 증빙 서류 업로드/검토 상태 조회.
*   **키오스크 관리:** 기기별 고유 식별자(UUID) 생성 및 등록, 포트원 연동 정보(Store ID 등) 설정.
*   **상품 및 카테고리:** 다중 카테고리 지원, 이미지 드래그 앤 드롭 업로드, 품절 처리 기능.
*   **정산/통계:** 포트원 관리자 대시보드 딥링크(Deep Link) 제공 및 기간별 매출 차트 시각화.

### 4.2 키오스크 프로그램 (Kiosk Client - Flutter)
*   **UI/UX:** 대형 터치스크린에 최적화된 상품 리스트 및 장바구니.
*   **결제 엔진:** PortOne SDK를 통한 오프라인 결제창 호출. 결제 완료 후 서버에 Webhook 또는 응답값 전송 후 승인 확인.
*   **상태 체크:** 네트워크 연결 및 단말기 포트 연결 상태 실시간 모니터링.

## 5. 단계별 개발 로드맵 (Roadmap)
*   **Phase 1 (MVP):** Supabase를 활용한 기본 인증 및 상품 CRUD 구현. 윈도우 환경에서 포트원 브릿지를 이용한 실제 결제 테스트 성공.
*   **Phase 2 (Alpha):** 파트너센터 웹 구축 및 매출 통계 대시보드 연결. 이용권 결제(빌링) 시스템 도입.
*   **Phase 3 (Beta & Scaling):** 안드로이드 키오스크 호환성 테스트. 1,000대 관리를 위한 중앙 모니터링 시스템 구축.
