# MOKI (모두의 키오스크) 프로젝트 상태 보드

이 문서는 집과 회사에서 Antigravity와의 대화 맥락을 끊김 없이 이어가기 위한 **프로젝트 상태 및 진행 기록 문서**입니다.

## 📌 [우리의 개발 원칙]
1. **연속성 유지:** 문서 기반으로 집과 회사의 개발 맥락을 완벽히 동기화합니다.
2. **유연한 기획 대응:** 기획안이 업데이트되면 이 문서에 반영하고 방향을 조정합니다.
3. **백엔드 성장 파트너:** FastAPI 개발 시 **상세한 주석과 원리 설명**을 통해 멘토링을 제공합니다.

## 🚀 기획안 요약 (Phase 1 MVP)
- **목표:** 중고 키오스크 범용 OS/App 보급 (SaaS/렌탈)
- **Tech:** Python 3.12, FastAPI, Supabase, Vite, Flutter, PortOne V2
- **핵심 기능:** 상품/카테고리 CRUD, 포트원 연동 오프라인 결제, 관리자 대시보드

## 🛠️ 현재 백엔드 진행 상태 (최근 업데이트)
- **완료된 기능:**
  - `User` 모델 및 Supabase 인증, 소셜 로그인 연동 (`social_login.py`)
  - 기본 CRUD 라우터 구축 (`Store`, `Category`, `Product`, `Order`, `Shelve`)
  - 기본 DB 아키텍처 및 CORS 설정 완료
- **진행 대기 중인 다음 목표 (택 1):**
  - [ ] PortOne(포트원) 결제 연동 백엔드 로직 (오프라인 결제 승인, Webhook 처리 등)
  - [ ] 장바구니 및 다중 상품 주문(Order) 트랜잭션 로직 고도화
  - [ ] 파트너센터용 매출 통계 API 개발

## 💬 Antigravity 연결 프롬프트 (새 대화 시작 시 사용)
> 기존에 진행하던 MOKI 프로젝트를 이어서 할거야.
> 프로젝트 내의 `docs/MOKI_STATUS.md` 파일을 먼저 읽고, 우리의 핵심 개발 원칙 3가지와 현재 진행 상황을 파악해줘.
> 파악이 완료되면, "진행 대기 중인 다음 목표" 중에서 오늘 시작할 코딩 작업을 나에게 제안해줘.
