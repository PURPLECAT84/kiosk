# 🧪 QA & REFACTORING TASKS (테스트 및 코드 품질 향상)

> **Role:** 백엔드/프론트엔드 작업 완료 후, 기능 테스트(단위/E2E)를 수행하고 코드를 리팩토링합니다.

## 🚀 QA 테스트 기본 원칙 (Black-box Testing)

1. **사용자 관점 테스트:** 완성된 코드를 눈으로만 리뷰하여 검증하지 않습니다. 반드시 실제 웹 브라우저(`browser_subagent`)나 프로그램을 구동하여 **사용자와 동일한 환경에서 버튼을 누르고 데이터를 입력하며 테스트**합니다.
2. **에러 발생 시 코드 리뷰:** 동적(Dynamic) 테스트 과정에서 버그나 화면 깨짐, 통신 오류가 발생했을 때만 소스 코드를 분석하여 원인을 찾고 수정(Fix)합니다.
3. **결과 기록:** 테스트 결과(성공/실패 영상, 에러 로그)를 명확히 기록하여 PM에게 보고합니다.
